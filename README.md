## À propos

Étudiant en informatique à EPITECH (MSc), à la recherche d'une **alternance**. J'ai un intérêt particulier pour le **DevOps** et **Cloud**, ce que reflètent les deux projets ci-dessous — sans m'y limiter.

J'ai construit un backend de messagerie temps réel en **Rust / Axum** (WebSocket, JWT, PostgreSQL + MongoDB), et déployé une application microservices sur **Kubernetes (GKE)** avec Traefik en reverse proxy et cAdvisor pour le monitoring.

Disponible dès maintenant, pour une alternance allant jusqu'à août 2028.

## Projets

### [nexus](https://github.com/Seizako/nexus) — messagerie temps réel

Application inspirée de Discord : serveurs, channels, messages instantanés. Backend **Rust/Axum** exposant une API REST et un hub **WebSocket** (présence, indicateurs de frappe), authentification **JWT**, et un choix de persistance à deux bases : **PostgreSQL** pour les données relationnelles, **MongoDB** pour l'historique des messages. Frontend Next.js, environnement de dev via Docker Compose.

`Rust · Axum · Next.js · PostgreSQL · MongoDB · WebSocket · Docker`

### [bernstein](https://github.com/Seizako/bernstein) — orchestration Kubernetes

Déploiement d'une application de vote microservices sur **GKE**, écrit intégralement en manifestes Kubernetes : Deployments, Services, ConfigMaps, PersistentVolume, Ingress. **Traefik** en reverse proxy avec sa configuration RBAC, et **cAdvisor** déployé en DaemonSet pour le monitoring des conteneurs.

`Kubernetes · GKE · Traefik · cAdvisor · PostgreSQL · Redis`

### [portfolio](https://github.com/Seizako/portfolio) — site personnel bilingue

Site vitrine FR/EN, déployé en continu sur Vercel à chaque push. — [**Voir en ligne**](https://ludovic-weng.vercel.app/)

`React · TypeScript · Vite · Tailwind CSS`

### [epitale](https://github.com/Seizako/epitale) — RPG 2D

Jeu de rôle inspiré d'Undertale : moteur de combat au tour par tour, dialogues et rendu tuilé. Projet EPITECH.

`Java · LibGDX`
